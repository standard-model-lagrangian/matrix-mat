# Exploratory Material Analyses

This directory archives standalone material characterization analyses, including:
- `nmr/`: PEG-DBCO macromer batch NMR spectroscopy audits and integral ratio analyses.
- `rheology/`: Hydrogel storage ($G'$) and loss ($G''$) modulus frequency sweeps.
- `paper_reproduction/`: Benchmarking datasets comparing local formulations to literature standards.
- `scripts/`: Supporting utility and exploratory plotting scripts.

These analyses are maintained separately from the primary `matrix-mat` high-content microscopy image processing pipelines.
