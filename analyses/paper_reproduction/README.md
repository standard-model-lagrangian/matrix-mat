# Paper Reproduction & Benchmarking

This directory contains benchmarking code and audit artifacts reproducing the active learning hydrogel discovery workflow from:

> Chen, Z., Miao, Z., Tom, G., Cheng, A. H., Wu, T., Kalhori, D., Hinz, B., Abolhasani, M., Kumacheva, E., Gusarova, E., Zondag, B., & Aspuru-Guzik, A. (2026). *Active Learning‐Accelerated Discovery of Fibrous Hydrogels with Tissue‐Mimetic Viscoelasticity*. **Advanced Functional Materials**, 2026, 48.  
> DOI: [10.1002/adfm.75639](https://doi.org/10.1002/adfm.75639)

## Reproduction Artifacts
- `audit/`: Bayesian optimization audit, candidate surrogate models, and benchmark evaluation scripts.
- `paper_text.txt`: Text extracts from the open preprint/article for claim verification.

Note: In accordance with repository hygiene and publisher copyright policies, the publisher PDF and supplemental documents are not tracked in version control; please access them directly via the DOI above.
